# 机器学习多因子选股研究

本项目以渤海证券《基于随机森林的多因子选股模型构建》为起点，研究历史中证500股票池上的多因子选股，比较随机森林、XGBoost、LightGBM，并加入验证集调参、交易成本、十分组回测与指数对冲实验。

**当前定位：可移植研究归档。** 本次整理保留此前模型和回测的计算逻辑与结果，没有重新执行全样本研究。检查发现旧版在构建回测集时也按未来收益标签只保留两端60%股票，存在事后筛选偏差。历史收益表不能直接视为无偏、可实盘的样本外业绩。详见 [已知限制](docs/KNOWN_LIMITATIONS.md)。

## 项目内容

- `src/`：分批下载、交易日历、动态历史成分、因子和标签处理，以及基线研究模块。
- `src/improved_v2/`：按时间划分训练/验证/测试/回测集，验证集选参，三类组合和十分组回测。
- `config/`：研究时间、模型参数、成本、路径；不含真实 Token。
- `results/reference/`：历史结果表、参数选择和数据集元信息，作为冻结快照。
- `reports/`：历史 Word 报告、16页 PPT、三张净值与回撤图，以及 HTML 结果总览。
- `docs/`：研究设计、数据字段、因子字典、结果说明、限制和本次更新。
- `tests/`、`tools/`：离线检查、公式回归测试和结果展示工具。
- `data/`、`outputs/`：本地运行数据及新结果，已配置 Git 忽略规则。

## 数据与环境

使用 Tushare Pro，配置期为2010-01-04至2025-04-30，基准为中证500 `000905.SH`，每20个交易日调仓。使用调仓日前最新可得的历史成分权重；行情与财务下载范围可能大于最终研究股票池。接口需要对应积分/权限，读者须自行获取合法数据，公开包不附带原始数据和完整训练样本。

建议 Python 3.11/3.12。在新建虚拟环境后运行：

```bash
python -m pip install -r requirements.txt
```

通过环境变量 `TUSHARE_TOKEN` 或本地 `.env` 配置凭证，格式见 `.env.example`。不要把真实 Token 写入配置或上传 GitHub。

## 完整运行

在项目根目录运行：

```bash
python run_research.py --stage check
python -m unittest discover -s tests -v
python run_research.py --stage download
python run_research.py --stage prepare
python run_research.py --stage research
```

最后三步也可用 `python run_research.py --stage all` 连续执行。下载较慢时可按 [英文 README](README.md) 的年份/财务分块命令续传。运行需足够内存和 API 权限；依赖文件使用版本范围，未声称不同环境能逐位重现旧结果。

如只想查看归档，不用 Token：

```bash
python tools/build_results_report.py
```

然后打开 `reports/results_overview.html`。此命令只读已有结果，不进行新回测。

## 结果与解释

历史回测区间约2020-08至2025-04。旧版随机森林“前10做多/中证500做空”记录累计收益121.67%、年化19.24%、Sharpe 0.791、最大回撤23.13%。这些数值来自原始结果表，受上述未来标签筛选及其他限制影响，只用于过程留档。不能据此断言策略可实现相同收益。

XGBoost 和 LightGBM 各比较6组保守参数，按验证准确率、验证 log loss、训练验证差距依次选择，再以训练+验证集重拟合；测试/回测指标不能再用于选参。早期665.32%的 XGBoost 结果来自回测表现选参，没有纳入本版主结果。
