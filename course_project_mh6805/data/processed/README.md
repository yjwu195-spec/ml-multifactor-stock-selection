# Locally generated panels

`python run_project.py --stage prepare` generates processed stock-level data here from authorized raw inputs. These outputs are ignored by Git. Aggregate public evidence lives in `results/`; it cannot replace these inputs for model fitting.

本目录由数据准备阶段生成，不公开个股级处理后面板。缺少原始输入时，不能用汇总结果表替代训练数据。
