# Course submission checklist

## Prepared

- Seven-page English final report including references.
- Fourteen-slide editable English PowerPoint with quantitative charts and speaker notes.
- Report source in LaTeX, style file and figure assets.
- Executable relative-path scientific code, fixed research configuration and dependency lists.
- Real-data cache retained locally, transformed panels, selected models and complete result tables.
- Equal-contribution statement for all three named members.
- Direct provider documentation links and teacher-feedback response matrix.
- Nine passing unit tests and passing real-output integration checks.

## Before uploading to the course platform

Check the actual presentation date and deadline in NTU Learn. Course instructions say PPT by noon the previous day, report/code and applicable data two days after presentation. Each group submits once and every member should speak and attend Q&A.

Submit Group12_Final_Report.pdf rather than only the .tex source. Source can accompany code. If recompiling LaTeX and substituting its PDF, independently inspect layout and the seven-page including-references limit; the supplied PDF is the verified seven-page rendering of the shared content.

Raw provider observations are retained for personal/local reproducibility. They are not an automatic public-submission artifact. The guideline allows accurate dataset descriptions instead of sharing sensitive/non-shareable data. Do not upload the entire GB-scale local directory publicly. Code, config, dependency files, tests, aggregate result tables, report/PPT and the data guide form the lightweight submission core. Confirm any platform-specific packaging requirement separately; none was specified in the supplied guideline.

## Deliverable assumptions

All results use newly executed experiments, not legacy internship charts. Financial revision vintages, realistic fills/price limits, actual dividend cash flows and fully executable shorts remain limitations. Notes and the report identify these boundaries. PPT NAV is monthly sampled for legibility; the report and CSV retain daily-open curves. Editable PPT chart arrays are rounded to 12 significant digits to fit spreadsheet precision, while source result files retain their numerical precision.
